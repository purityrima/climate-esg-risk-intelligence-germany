## Project Overview

This repository contains the source code, datasets, documentation, and experiments for developing an AI-powered Climate & ESG Risk Intelligence Platform that estimates regional climate-related financial risks for the German banking sector using explainable deep learning, geospatial analytics, and ESG indicators.

The platform integrates climate hazards, ESG indicators, socioeconomic vulnerability, and geospatial information using deep learning to generate a Regional Climate Risk Index (RCRI) at the NUTS-3 district level.

The system combines PyTorch, GeoPandas, SHAP explainability, Flask REST APIs, and interactive visualizations to support climate-informed financial decision-making.
